    Blue's Informations Log // STN25XR
    Mini rapport • Star-date 2026.03.12 • Sector: Oxnehaga / Huskvarna
    Mission Type: Digital City Recon System Core: ArcGIS SceneView Status: Operational Report Level: Deep Dive

    Entry 00 // Mission Context

    BLUE guides this project as an interactive 3D city mission console. The objective is to explain clearly how the website is built, where data comes from, which API web addresses are used, and how building/elevation values are calculated.

    Entry 01 // How It Was Done (Implementation)

    • Built as a single-page app centered in index.html with ArcGIS SceneView as map engine.
    • Feature logic split into modules: bus15.js, pm25Live.js, windLive.js, cloudWms.js, and elevationProvider.js.
    • UI split into three operational panels: Menu, Digital City, and BLUE/Information.
    • Hybrid data pipeline: local GeoJSON + live API requests + route/elevation processing in browser.

    Entry 02 // System Structure Behind The Website

    • UI/Controls layer: tabs, toggles, popup flows, modal windows, and simulation controls.
    • Map/render layer: ArcGIS 3D scene + thematic layers + custom graphics overlays.
    • Analysis layer: distance, route selection, nearest services, and elevation sampling.
    • Integration layer: weather, transport, air quality, cloud imagery, and electricity prices.
    • Data storage layer: local files in /data and browser cache/localStorage for selected runtime data.

    Entry 03 // API Web Addresses (Live Integrations)

    • ArcGIS JS API: https://js.arcgis.com/4.30/
    • Open-Meteo weather: https://api.open-meteo.com/v1/forecast
    • Open-Meteo wind (ECMWF): https://api.open-meteo.com/v1/ecmwf
    • Open-Meteo elevation fallback: https://api.open-meteo.com/v1/elevation
    • OpenTopoData elevation fallback: https://api.opentopodata.org/v1/srtm90m
    • ResRobot departure board: https://api.resrobot.se/v2.1/departureBoard
    • ResRobot nearby stops: https://api.resrobot.se/v2.1/location.nearbystops
    • Samtrafiken GTFS static: https://opendata.samtrafiken.se/gtfs/jlt/jlt.zip
    • OpenRouteService walking: https://api.openrouteservice.org/v2/directions/foot-walking/geojson
    • OpenRouteService driving: https://api.openrouteservice.org/v2/directions/driving-car/geojson
    • OSRM fallback: https://router.project-osrm.org/route/v1/driving/...
    • SMHI/Naturvardsverket PM2.5: https://datavardluft.smhi.se/52North/api/
    • NASA GIBS cloud tiles: https://gibs.earthdata.nasa.gov/wmts/epsg3857/best/
    • SE3 electricity prices: https://www.elprisetjustnu.se/api/v1/prices/
    • Skyddsrum Feature Service: https://services6.arcgis.com/.../Skyddsrum_220225/FeatureServer/1

    Entry 04 // Building Height + Elevation Protocol

    • Primary building extrusion source: attribute b_Hight_m in data/Main_byggnad.geojson.
    • If height is missing, fallback extrusion is set to 5 m.
    • Scenario control: two selected buildings are force-set to 18 m for simulation visibility.
    • Route elevation profile is sampled from ArcGIS ground query; additional sampling can come from elevation provider data and API fallback chain.

    Entry 05 // Local Data Files Used

    • data/Main_byggnad.geojson (building footprints + attributes)
    • data/Oxnehaga-Area.geojson (area boundary)
    • data/Busshallplaster_oxnehaga.geojson (bus stop local layer)
    • data/Fastighet_punkter.geojson, data/Komunal_mark.geojson, data/Vatten_jonkoping_01.geojson
    • data/Forskola.geojson, data/GrundskolaPoint.geojson, data/Gymnasieskolal.geojson, data/VardcentralPoin.geojson
